# chess-com-hide-material

A Chrome extension that hides the material balance on Chess.com: the captured pieces and the
"+N" material advantage score next to each player. You have to keep track of material on the
board alone.

It only hides content locally with a stylesheet. It runs no scripts, sends no requests and
reads no game data.

## Install

1. Open `chrome://extensions` and turn on Developer mode.
2. Click "Load unpacked" and select this repository's root folder.

To see material again, disable the extension and reload the page.
